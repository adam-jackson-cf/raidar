# Step 2 Workflow: Select Improvement Hypothesis

## Objective

Choose one generalizable, evidence-backed improvement.

## Required actions

1. Prioritize deterministic enforcement gaps, verification clarity, prompt ambiguity, or resource inefficiency based on evidence.
2. Avoid one-off fixes tied to a specific previous scenario or run.
3. Define expected measurable effect before editing.

## Done when

- One improvement hypothesis is selected.
- Expected measurable effect is stated.
- The change is conceptual and reusable.
