# Step 4 Workflow: Run Baseline

## Objective

Create the first evidence point before any revision work.

## Required actions

1. Run the target AgentSpec against the baseline.
2. Collect aggregate and run-level evidence.
3. Use the results as input to the revision skill instead of pre-authoring revisions.

## Done when

- Baseline run evidence exists.
- Results are ready for revision analysis.
- No future revision was authored before analysing the baseline.
