# Step 2 Workflow: Author Baseline

## Objective

Create the scenario baseline artifacts consistently.

## Required actions

1. Create or update the scenario root using the public workflow.
2. Align prompt, rules, starter, verification, acceptance, metrics, and score_profile.
3. Prefer deterministic checks before judge-based scoring.
4. Keep instructions conceptual, reusable, and non-scenario-specific.

## Done when

- Scenario artifacts are coherent.
- Deterministic evidence is preferred where possible.
- No instruction is tailored to a previous one-off failure.
