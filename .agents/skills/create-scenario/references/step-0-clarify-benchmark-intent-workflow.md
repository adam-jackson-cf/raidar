# Step 0 Workflow: Clarify Benchmark Intent

## Objective

Define what the scenario should measure before authoring files.

## Required actions

1. Capture target task, target capability, constraints, non-goals, and intended evidence.
2. Identify whether the benchmark is delivery-quality, resource-efficiency, visual fidelity, or another scoring emphasis.
3. Decide whether evidence should come from one AgentSpec or a stored matrix of scenario revision and AgentSpec entries.
4. Reject scenario-specific carryover that would not apply to future scenarios.

## Done when

- Benchmark intent is explicit.
- Evidence expectations are known.
- Benchmark run shape is explicit.
- No one-off scenario finding has been encoded as a general requirement.
