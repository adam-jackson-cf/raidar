# Step 1 Workflow: Select Scoring Contract

## Objective

Choose the stable scoring contract for comparable revisions.

## Required actions

1. Select score_profile id, baseline lineage, metric weights, and enabled metrics.
2. Confirm every weighted metric is enabled and configured.
3. State that changing score_profile id, weights, weighted metrics, verification, or acceptance starts a new baseline.

## Done when

- score_profile is explicit or legacy scoring is deliberately accepted.
- Metric support is configured.
- Comparable-contract boundaries are documented.
