# Customer journeys

The surface is designed as a single funnel, not three disconnected tools. The
canonical journey — [compare → explain → trace](./customer-journey.md) — walks
a reviewer from a fleet-level verdict down to the exact span that explains a
failure, handing off between [personas](../personas/index.md) at each step.

- [Compare → Explain → Trace](./customer-journey.md) — the primary journey.
